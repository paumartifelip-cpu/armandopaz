# Armando Paz 🕊️ - El Pacificador de Reseñas de Google Maps

**Armando Paz** es una plataforma web minimalista y ultra-eficiente diseñada para comercios locales, PYMEs y agencias. Permite extraer y responder de forma masiva a **TODAS** las opiniones de los clientes en Google Maps en 1 solo clic.

---

## 🚀 Características Principales

- 📍 **Extracción Automática por Enlace**: Pega cualquier enlace de Google Maps y la aplicación identifica el negocio y procesa sus reseñas.
- 🕊️ **Pacificador de Quejas**: Transforma críticas negativas de 1 estrella en respuestas amables, empáticas y orientadas a la reconciliación.
- 🚀 **Posicionamiento en Google Maps**: Genera respuestas que destacan el nombre de tu negocio y tu ciudad para subir puestos en búsquedas locales.
- 🤖 **Soporte de Inteligencia Artificial Dual**:
  - **Google Gemini 1.5 Flash**: 100% Gratuito (sin tarjeta de crédito).
  - **OpenAI (`gpt-4o-mini`)**: Modelo recomendado por su alta velocidad y coste ultra-económico ($0.15 por millón de tokens).
  - **Modo Rápido Directo**: Funciona inmediatamente sin configurar claves.
- 📐 **Diseño Minimalista Suizo**: Estética sobria en blanco y negro con bordes 100% rectos (`0px border-radius`) y tipografía *Space Grotesk* e *Inter*.

---

## 💻 Cómo ejecutarlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/paumartifelip-cpu/armandopaz.git
   cd armandopaz
   ```

2. Ejecuta el servidor Python:
   ```bash
   python3 server.py
   ```

3. Abre en tu navegador:
   👉 **http://localhost:8080**
